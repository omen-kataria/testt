About

What is Blackline?

Blackline is a minimal, client-side student portal built entirely with vanilla HTML, CSS, and JavaScript. It reads academic data from a local JSON file and delivers a complete experience — grades, projects, skills, certifications, and a professional student directory — all without a backend server.

Designed with glassmorphism aesthetics, smooth transitions, and a monochrome palette, Blackline proves that modern web experiences do not need heavy frameworks or complex toolchains.

Every student gets a unique profile based on their semester data. Profile customizations are saved locally in the browser using localStorage.
